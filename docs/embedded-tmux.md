# Embedded tmux

This repo embeds pinned-version tmux binaries for owlx.
System tmux is not used.

Supported embedded platforms:

- `linux/amd64` (static)
- `darwin/amd64`
- `darwin/arm64`

## Default paths (patched)

The tmux build is patched for owlx to support fixed defaults:

- Default config path: `~/.owlx/tmux/default/tmux.conf`
- Default socket path: `~/.owlx/tmux/default/tmux.sock`
- Build-time patch: `TMUX_SOCK_PATH` for fixed socket path
- Tilde expansion: `~` expands even when the file does not yet exist

## Embedded binary

The embedded tmux binary is generated locally at:

- `assets/tmux/<os>_<arch>/tmux` (not committed; generated by the build script)

Build outputs (local cache by default):

- Standard: `~/.cache/owlx/tmux-static/bin/tmux.<os>-<arch>.gz`
- Stripped: `~/.cache/owlx/tmux-static/bin/tmux.<os>-<arch>.stripped.gz`
- Unpacked: `~/.cache/owlx/tmux-static/bin/tmux.<os>-<arch>`

We embed the **stripped** binary to reduce size.

## Updating the embedded tmux

1) Build or install the embedded binary (recommended):

```sh
# Option A: build using the bundled script (preferred)
scripts/build-embedded-tmux.sh

# Option B: use a prebuilt artifact
TMUX_STRIPPED=/path/to/tmux.<os>-<arch>.stripped.gz scripts/build-embedded-tmux.sh
```

The bundled script is derived from build-static-tmux (see
`scripts/build-embedded-tmux.LICENSE`) and produces the stripped artifact under
`~/.cache/owlx/tmux-static/bin/` by default.

Build metadata defaults live in `assets/tmux/buildinfo.env`. Edit that file to
change tmux/libevent/ncurses/musl versions or default paths. `make tmux-update`
will rebuild if this file changes.

1) Verify platform format:

```sh
file assets/tmux/<os>_<arch>/tmux
```

Expected output:

- Linux: `ELF 64-bit ... statically linked`
- macOS: `Mach-O 64-bit executable ...`

1) Run tests (after the embedded binary exists):

```sh
go test ./...
```

## Makefile integration

By default, `make build` will run `make tmux-update` first.
You can also supply an existing artifact with
`TMUX_STRIPPED=/path/to/tmux.<os>-<arch>.stripped.gz`.
